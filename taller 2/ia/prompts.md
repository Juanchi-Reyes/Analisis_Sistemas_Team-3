PRONT UTILIZADO PARA ANALIZAR LAS DIMESNIONES DE PESTEL

Actúa como analista de sistemas crítico. Estamos realizando el análisis PESTEL de un sistema de seguimiento y gestión de proyectos académicos universitarios. Ya tenemos algunas ideas:



Tecnológico: incompatibilidad, fragmentación de información y obsolescencia de plataformas actuales.



Social: necesidad de visibilizar proyectos académicos y conectarlos con empresas o comunidad.



Legal: propiedad intelectual, protección de datos personales y regulaciones según el área de los proyectos.



Genera alternativas para las dimensiones que aún faltan: Político, Económico y Ecológico/Ambiental.



Para cada dimensión propón posibles factores, explica cómo podrían afectar al sistema y señala qué información sería necesario verificar para determinar si realmente son relevantes.



No inventes datos ni afirmes que un factor es importante sin justificarlo. Presenta alternativas, no decisiones definitivas."



Se utilizó la IA principalmente para ideación y ampliación del análisis, buscando alternativas para las dimensiones de PESTEL que todavía no habíamos desarrollado.



La IA no tomó la decisión definitiva sobre los factores. Sus propuestas fueron utilizadas como punto de partida para que el equipo pudiera posteriormente revisarlas, cuestionarlas y determinar cuáles podían ser pertinentes para el sistema





"Ahora actúa como revisor crítico de nuestro análisis PESTEL completo. Revisa las seis dimensiones: Político, Económico, Social, Tecnológico, Ecológico/Ambiental y Legal.



Identifica:



Factores demasiado genéricos.

Factores que realmente no condicionan nuestro sistema.

Factores que podríamos estar omitiendo.

Confusiones entre problemas internos del sistema y factores externos del entorno.

Qué factores deberían considerarse prioritarios.



Para cada observación, explica qué evidencia necesitaríamos para validarla. No tomes la decisión por nosotros; plantea alternativas y críticas."



Este segundo prompt se utilizó para crítica y detección de omisiones. Después de tener propuestas para las seis dimensiones, se pidió a la IA que cuestionara el análisis en lugar de simplemente generar más factores.



El objetivo fue identificar posibles problemas como:



factores demasiado generales;

factores que podrían ser problemas internos del sistema y no factores PESTEL;

aspectos del entorno que podrían haberse omitido;

factores que necesitarían evidencia antes de considerarse relevantes.



La respuesta de la IA se tomó como una revisión externa del análisis, pero las observaciones fueron posteriormente analizadas por el equipo.
